## 实际纠错与修复

- 画像漏列引用、财务引用拼写/缺少必需计算、估值漏列交叉引用、报告一处数字绑定错误，
  均由既有 validator 拒绝并反馈；各阶段在允许的一次补跑内修正，没有放宽标准。
- 后端全量首次 796 通过、1 失败、1 跳过，失败是 UI 边界测试仍要求旧首页标题。
  按已确认 V2 修正：保留现有 h1 的正向检查，增加 Agent／直连条件和两种标签检查。
  针对测试 12/12；模式判定颠倒和标签损坏的内存变异均被拒；最终全量恢复 797/798、1 跳过。
- 真实 Codex 两轮范围审查：首轮指出开发文档登录目录表述歧义，以及应保留新版 h1 正向覆盖；
  两项已处理，复审 `No actionable regressions`。不是新一轮整仓审计。
- HTTP 检查第一轮要求附录存在而失败；确认 `--no-archive` 按原设计跳过附录后，
  单独调用生产 `writeViewer` 并重测通过。没有改 manifest、没有修改原报告、没有补写知识库。
  渲染器 gate_removed=1，不把衍生展示净化说成零处理。自动归档链路本批没有重新实跑。
