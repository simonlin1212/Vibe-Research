## 本批四项

| 问题 | 修复与可观察结果 |
|---|---|
| 不同数据根共享同名快照 | 内存缓存按规范化绝对文件路径索引；两个目录独立，等价路径同义，磁盘回填也隔离 |
| 普通工具继承模型 key / VRA 私密配置 | calc/backtest 工具只继承既有取数基础环境白名单；模型运行自己的凭据环境不变 |
| 同名辩论覆盖在途结果 | 已存在的编号在替换前拒绝，返回 `debate_exists` 和重开提示，不改变原场状态 |
| 辩论中止仅停界面 | 页面信号传入 HTTP、服务层、取数进程和模型 SDK；取消时保留已完成阶段，余下阶段标 cancelled，晚到正文不记完成 |

资料包构建期间取消：中断当前取数、不继续拉下一源、不创建空场次。
阶段执行期间取消：整场 `done=true / outcome=cancelled`，已完成正文保留在该场内存状态中；
这里不是增加“中止自动归档”能力。提前取消的请求不占用阶段；普通模型失败仍允许推进下一阶段。
默认与页面指定 API 来源都使用每阶段独立、非持久模型会话。
