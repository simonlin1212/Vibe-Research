# M12 跨来源业务验收（本地未提交）

基线 `feat/dual-engine` / `2ed80ac`。本批没有提交、推送或发布。

## 用户路径

AI 来源仍只在设置中选择一次，Agent 默认开启。Claude Code、WorkBuddy / CodeBuddy 的多空辩论、
Agent 回测和资料转写走各自真实 CLI，不暗换 Codex，也不把直连模式悄悄升级为 Agent。

“我的持仓”新增截图／表格导入：选择文件 → 生成草稿 → 对照原件核对 → 填入可编辑表单 → 明确点击添加。
上传或填表本身不写台账；同代码已有持仓时拒绝直接带入，避免把总持仓当新增数量叠加。
只带入代码、数量和成本，不自动填名称、账户、日期或备注。文件内容会发送给所选 AI，界面明确披露。

## 实现边界

- Claude 转写只开放本批授权文件的受控读取工具；文件名、大小、哈希与路径均检查。
- WorkBuddy 原生图片通过其图像输入接口传入；文本仍经受控读取工具。最多十份图片、总输入有大小上限。
- 工具读取回执只证明返回过字节，不证明模型读懂；每次尝试重新计回执，损坏回执和原文件变化直接失败。
- 转写和结构化参数最多两次同来源尝试；不清洗失败成成功，不重复执行已成功的真实业务工具。
- 辩论单轮内部期限十分钟，普通对话仍三分钟；用户不能从 HTTP 任意设置期限。取消继续向下传递。
- 本地 CLI 适配不等同于 Codex hooks / skills 或跨阶段连续线程；这些差异仍保留在运行记录中。
