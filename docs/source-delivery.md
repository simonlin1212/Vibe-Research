## 基线与范围

本次开始时核对公开 main、latest Release v1.1.0 与本地 HEAD：均对应
`f15ab898dc5d9a900d5f78ac864e7730f2f114bc`。从这份已公开源码继续，放弃本地 M41 动态板块改造。
板块中心仍为原发布版本，不引入动态板块、新建行业研究等未发布功能。

暂撤原因：让使用者的开发 Agent 直接修改项目源码，避免围绕封装后的 Mac App 改造。
撤客户端不会自动赋予产品内置研究 Agent 修改源码的权限；开发改造仍由使用者自己的开发工具完成。

移除范围：Mac 原生窗口、图标打包资产、Python 打包锁、构建和签名/公证脚本、
Mac 专属后端启动入口与静态页面网关，以及只针对这些产物的测试。
通用的受控研究执行模式和 Python 不生成字节码的回归测试保留。

保留范围：`desktop/` React + Vite 浏览器 UI、`orchestrator/` 后端、Codex SDK/引擎 0.153.4、
Claude Code / WorkBuddy / API 接入、首页对话、Agent 默认关闭、原侧栏和所有 v1.1.0 研究功能。
`desktop` 只是现有前端目录名，不是残留的 Mac 原生客户端。

## 运行与开发

先安装 Git、Node.js ≥ 22.18（推荐 24 LTS）与 Python ≥ 3.11（推荐 3.12）。
macOS / Linux 在仓库根运行 `scripts/setup`，然后运行 `scripts/start`；
Windows 运行 `scripts\setup-windows.cmd` 和 `scripts\start.cmd`。
默认浏览器地址 `http://127.0.0.1:5930`，后端回环端口 8765。
这些是默认地址，不代表当前已有服务正在运行；端口占用时先确认所属项目，不终止其他服务。

把克隆的项目文件夹交给自己的开发 Agent，修改前阅读项目说明与相关模块，修改后运行 README 中的测试。
初始化会安装依赖、建立私有数据区；不需要单独安装全局 Codex，但仍需连接自己的 AI。
